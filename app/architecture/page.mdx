# Architecture

Solidarity's architecture is built on three core principles: **local-first**, **privacy-first**, and **open standards**.

## Architecture Layers

```mermaid
flowchart TD
    A["App Layer\niOS 17+ · Swift / SwiftUI · @Observable MVVM"]
    B["Exchange Protocol Layer\nOID4VP · OID4VCI · SIOPv2 (v2)"]
    C["Verifier Web Layer\nSelf-hosted Static Web + WASM ZK Verifier"]
    D["Data Format Layer\nW3C VC + ZKP (passport) · SD-JWT VC (general)"]
    E["ZK Proof Layer\nOpenPassport Circuits (Noir) + mopro (prover)"]
    F["Identifier Layer\ndid:key · did:jwk (pairwise per-RP)"]
    G["Key Management Layer\niOS Keychain · iCloud Keychain sync · Shamir SSS"]

    A --> B --> D --> E --> F --> G
    B --> C
```

DID key lifecycle, iCloud Keychain sync, Social Recovery (Shamir SSS).

**Highlights**: PassKit, PKCS#7 detached signature, stateless backend
