# Screen Components Guide

A developer-focused breakdown of view hierarchy, data flow, and service layer for all three main tabs.

---

## App Entry Point

```swift
// solidarity/SolidarityApp.swift
// solidarity/AppDelegate.swift
// solidarity/Views/Common/MainTabView.swift
```

App launch → returning user: Face ID → Tab Bar. First launch: Onboarding flow (O-1 → O-5).

## Tab 1 — People

### Component Tree

```
PeopleListView
├── NavigationBar [People] [＋] [↔ Exchange]
├── SearchBar (local filter by name/company/title)
├── Section: Verified
│   └── ContactRowView (for each isVerified=true Contact)
│       ├── AvatarView (animal character or photo)
│       ├── Name + Company
│       ├── ✅ Exchange date
│       └── Ephemeral message snippet (theirEphemeralMessage first 50 chars)
├── Section: Contacts
│   └── ContactRowView (imported or manually added contacts)
└── EmptyState [PL-1e] or [PL-1v]
```

**Views**: `solidarity/Views/PeopleViews/PeopleListView.swift`

### Person Detail Component Tree

```
PersonDetailView [PL-2]
├── NavigationBar [← Back] [Share] [Edit]
├── AvatarView
├── Header (name, company/title, ✅ verification status)
├── Ephemeral Message Section (only shown for isVerified=true)
│   ├── My message (myEphemeralMessage)
│   └── Their message (theirEphemeralMessage)
├── Contact Info Section
│   ├── 📧 Email
│   ├── 📱 Phone
```

**Views**:

- `solidarity/Views/MatchViews/ShareLinkOptionsView.swift`

**QR Services**:
- `solidarity/Services/Card/QRCodeGenerationService.swift`
- `solidarity/Services/Card/QRCodeModels.swift`

### QR Format Reference

| Format | Description | Receiver-side handling |
|--------|-------------|----------------------|
| `plaintext` | Plain text card snapshot | Direct parse |
| `zkProof` | Encrypted payload + issuerProof/sdProof | Decrypt + verify proof |
| `didSigned` | Compressed JWT VC string | JWT verify → import as credential |

## Apple Wallet Integration

PassKit `.pkpass` flow:

```
WalletPassGenerationView (CardViews/)
└── PassKitManager
    ├── createPassBundle() — assemble pass.json locally
    ├── generateManifest() — SHA256 hashes of assets
    ├── signManifest() — POST to Cloudflare Worker
    └── PKAddPassesViewController — let user add to Wallet
```

The QR barcode in the pass contains an app import URL, so recipients can import it as a Solidarity contact.

**Code**:
- `solidarity/Services/Sharing/PassKitManager.swift`
- `solidarity/Services/Sharing/PassKitManager+Generation.swift`
- `solidarity/Views/CardViews/WalletPassGenerationView.swift`
